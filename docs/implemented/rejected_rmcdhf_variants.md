# 已否决 RMCDHF 独立变体的移除

2026-11-11，按用户确认的否决决定，移除 `rmcdhf_mem_strict_mpi` 和
`rmcdhf_mem_diag_mpi`。此前只移除了 orbopt 系列，却错误地在指南、构建和验收清单中
继续保留这两个变体；本次纠正该遗留状态。

现行普通求解器为 `rmcdhf`、`rmcdhf_mem`、`rmcdhf_mpi`、`rmcdhf_mem_mpi`。
CSFG 仍处于原有的独立可选边界。F2018 的 Check/Audit 编译诊断配置继续保留；
它们与本次删除的 SCF 严格停止/P0 追踪程序不是同一功能。

清理范围包括：

- 两个完整源码目录、CMake 构建和安装目标。
- 严格停止、轨道一致性、P0/START 追踪、专用重启测试，以及对这两个变体的公共测试实例。
- 网格补丁、当前验收清单、警告基线中对应的入口和覆盖。
- 现行程序介绍、专用运行说明和过时的“保留 strict/diag”工作规范。
- 当前本地构建中的同名程序及专用目标产物，避免目录删除后误用旧二进制。

普通求解器的实现及其 SCF 判据保持原样，没有把被否决变体的算法合并到普通版本。
固定一轮对照脚本所需的普通程序 stdin 已独立保留，不再导入被删除的 strict 重启测试。
`atomic-suite` 网格布局现为 19 个入口，RCI 续算入口仍为 4 个；上游 `grasp2018` 布局不变。

历史评审中提到的这些变体和旧测试数量仅描述当时版本，相关链接指向本退役说明。
旧代码可从 Git 历史追溯，已有压缩备份也可能包含历史二进制；这些都不是当前支持入口。
本次没有创建替代目录、兼容别名或新的求解器分支。
