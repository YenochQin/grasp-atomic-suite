# 普通 RMCDHF MPI 的 MCP 读取与每轮收缩

2026-11-22，基准源码为 Suite `c1377aa0`。`3.4dev1` 的 `rangular_mpi`、
`rmcdhf_mpi` 和 `rmcdhf_mem_mpi` 使用相同的带目录格式。生产冷／热缓存、峰值 RSS 和
最慢 rank 墙钟的验收步骤见[实施计划](../plans/rmcdhf_mcp_io_2026-11-22.md)。

## MPI 计算链

直接运行 `rangular_mpi`，各 rank 在工作目录生成一个 `mcp.mcpidx`。随后以相同的 rank 数、
进程布局和描述符基组运行 `rmcdhf_mpi` 或 `rmcdhf_mem_mpi`。同一工作目录连续生成时，各 rank 完成写入后才发布新分片。已有旧 MCP 的计算可用新版本 `rangular_mpi` 重新生成。读取遇到缺失、截断或身份不符的分片时
通过 MPI 报错。

普通 MPI 求解器在首次调用势系数构造时收缩所需积分组。EOL 在每次混合系数、能级权重和广义占据数更新后
重建收缩表。EAL 在其固定权重下首次构造后复用表。普通和追加更新覆盖所有可变轨道，Lagrange 乘子选中的
冻结侧也纳入积分组并集。每个相关组按原贡献顺序求和，DA、YA、XA 保持原标签及累加顺序。径向势和矩阵
使用各调用时的径向函数。收缩阶段按各 rank 的最大稀疏块和目录组数分配工作区，EOL 在下次矩阵装配前释放。
任一 rank 的工作区分配失败时，MPI 作业报告相关分片和错误。

MPI 内存版读取同一目录，将结构和系数装入原有求解数组。串行计算使用配套的串行 `rangular` 和
`rmcdhf`／`rmcdhf_mem`。历史对照工具可以读取两种磁盘格式。

## 计数与诊断

- `rangular_mpi --timings timing.csv` 输出每 rank、块和通道的生成、排序及写出时间和记录数。
  当前生成器按块、通道排序，系数排序数组约占每条贡献 20 字节。生成端的临时记录、排序下标与
  块内稀疏位置使用有界的 32 位整数，到达上界时报告错误。全块非零数和三角容量按 64 位计算。
- `rmcdhf_mpi --mcp-trace` 在各 rank 工作目录写 `mcp.io.csv`。`epoch` 随 EOL 密度权重更新递增。
  结构行记录本地稀疏块读取、行号数及字节。通道行记录读过或跳过的组、贡献数、字节和最大组。
  缓存行记录结构、收缩表、工作区估计和分配大小。阶段行记录矩阵装配、势系数构造、径向计算、
  归约、普通及追加更新、径向求解失败重试和每轮 SCF 墙钟。
- `bytes_read` 计应用消费的逻辑记录或流内容，包括已消费的标签和目录，以字节表示。跳过的负载大小单列。设备和页缓存的流量需用目标系统计数器量测。
  矩阵已有的 barrier 和归约分别计时，归约耗时可包含等候较慢 rank 的时间。
- `rmcdhf_mpi --mcp-verify` 在各 rank 工作目录写 `mcp.bits`，记录收缩和、DA/YA/XA 的标签和值、
  矩阵、乘子及径向数组的 IEEE 64 位模式。性能对照时关闭此选项。

## 带目录格式第 1 版

无格式流，使用单字节文件存储单元与一基字节位置。头含 `GMCPIDX1`、版本、端序标记、字段宽度、
轨道标签基数、表示标记、生成批次、rank 及进程数、基组尺寸、相互作用标志和目录位置。
其 64 字符基组标识采用已验证的 V3 Parquet SHA-256，Parquet 元数据绑定轨道表和 CSF 块顺序对应的 TOML。
读取时核对各分片的元数据和生成批次，并与实际用于求解的描述符匹配。

块目录记录标签、CSF 数、零阶截止、稀疏块位置及本地列和行数。每通道还记录首组索引、组数与贡献总数。
数据顺序为块、紧凑列终点与稀疏行号、T/V 通道、升序标签组。组目录在数据尾部，每项四个 64 位字段，
依次为字节位置、字节长度、标签和贡献数。偏移和磁盘计数均为 64 位。每条 16 字节贡献含 32 位本地
稀疏位置、32 位 CSF 列和原始 IEEE binary64 系数，磁盘次序为列、位置、系数。稀疏列终点与行号也使用
32 位字段。组负载按最多 65,536 条贡献分段传输，段在磁盘上连续。写完数据与目录后，所有 rank 到达
同步点才写完成尾标 `MCPDONE1`。读取验证文件长度、块及组目录边界、位宽、标签、列和位置等字段。

矩阵组件直接定位到有选根的块。收缩组件在块内首次命中积分组时装载该块的结构。组目录分批读取，标签筛选后按原排列读取
命中的负载。每次缓存建立只消费一次命中的积分组。

## 本地验收

GNU Fortran 16.2.0 的 Debug 构建用双 rank、两个对称块及两轮 EOL 对照所保存的旧路径结果。
选取第一块的一个根、冻结两个轨道，并覆盖冻结侧乘子和追加轨道改善。

| 路径 | 两轮势系数路径消费的逻辑字节，两 rank 合计 |
| --- | ---: |
| A · 旧 MCP、旧扫描 | 18,000 |
| B · 旧 MCP、收缩缓存 | 2,176 |
| C · 带目录 MCP、收缩缓存 | 1,088 |

A、B 为上轮保留的历史测量。现行单路径重复测得 C 的 1,088 字节。各组收缩、DA/YA/XA、矩阵、乘子、
径向势及最终 `.mix`、`.wfn` 与旧路径逐位相同。目录格式跳过了未选根块的矩阵数据。
回归覆盖空 rank、空通道、跨段组、超过 32 位的文件位置、64 位稀疏统计、基组和分片身份不匹配、
截断及两种 MPI 求解器的正常入口。

