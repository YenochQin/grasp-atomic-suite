# 输出格式内联

2026-11-20 完成源码迁移。迁移基准为 `2d4c721` 及实施前工作树中已有的修改。

原先引用数字 `FORMAT` 标签的 `WRITE` 和 `PRINT` 现在直接使用字符格式。例如，RMCDHF 各版本的摘要用下列格式输出原子序数。

```fortran
write (24, '("The atomic number is ",1f14.10,";")') nuclear_charge
```

内联保留字段宽度、小数位数、指数格式、比例因子、重复组和格式回退。字面文本及其空格、输出单元、I/O 控制项和输出项顺序沿用迁移前的代码。长格式在格式描述符之间续行。

| 范围 | 源文件 | `WRITE` | `PRINT` | 删除的 `FORMAT` | 其中原无引用 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 共享库 | 31 | 60 | 0 | 53 | 3 |
| 应用 | 173 | 843 | 2 | 725 | 85 |
| 合计 | 204 | 903 | 2 | 778 | 88 |

逐程序单元盘点确认没有 `READ` 或间接格式引用依赖这些标签。既有的列表导向输出、输入格式和控制流标签均保留。56 个导入的 RMCDHF 文件纳入新增的来源快照，链接至前一份 GRASP MPI 命名快照。[RMCDHF 来源快照](../reference/rmcdhf_inline_output_formats_snapshot.json)
