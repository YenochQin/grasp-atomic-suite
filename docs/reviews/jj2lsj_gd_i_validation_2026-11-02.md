# jj2lsj_omp：Gd I 真实输入兼容性验证

日期：2026-11-02。实现基线：`3630f42466418bf02c7f927d5bcd8c3f1663ccd5`。

## 目的与结果

检验 OpenMP 转换在实际大型输入上是否保持串行结果。预期为同输入、同能级、同阈值下，标签逐字节相同、完整双精度系数逐位相同；性能不预设加速倍数。

**六套输入全部通过 4 线程生产程序回放，18 个标签/唯一标签文件与历史结果逐字节相同。** ZF-AS1 与 RCI-AS4 的默认筛选后共 994,894 个带符号 LS 系数，在 4 和 8 线程下均与串行逐位一致，位差异数和最大绝对差均为 0。

这验证转换实现的兼容性，不验证原 MCDHF/RCI 计算的物理精度或收敛性。

## 测试设置

- 数据集合：`973_o1_vv1`，ZF-AS1～AS4 使用 `.m`，RCI-AS2/AS4 使用 `.cm`。每套包含六个 block、十个目标能级。
- 全部目标能级；最大遗漏权重 1%，计算阈值 0.005，打印阈值 0.001；生产程序启用唯一标签。
- Linux、AMD Ryzen 7 7800X3D（8 个可用核心）、GNU Fortran 16.2.1；Release 构建。
- `OMP_DYNAMIC=FALSE`、`OMP_PROC_BIND=close`、`OMP_PLACES=cores`、`OPENBLAS_NUM_THREADS=1`。作业依次执行。
- 原始输入和历史结果保留，测试输出在独立目录。没有重新运行 SCF/RCI、提交集群作业或修改转换源码。

## 既有提示和验证边界

AS1 的原始串行与新版均存在 `IEEE_DIVIDE_BY_ZERO` 状态提示，以及部分能级未达到 1% 遗漏权重目标的提示。数值与标签一致不消除这些既有问题；本次未定位浮点状态标志的具体产生点。

本次覆盖给定数据的默认筛选与目标集合；不覆盖无筛选完整空间、生产规模 `.lsj.T` 文件读写、其他编译器或任意线程数。没有修改占据筛选算法，也没有据此判定轨道或观测量物理收敛。
