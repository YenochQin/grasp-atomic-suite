# Zn I AS1 多根 RMCDHF 收敛与逐 rank 峰值内存

2026-11-27，四种 RMCDHF 在 Zn I 的完整 AS1 偶宇称生产算例上都在第 16 轮达到 SCF 停止条件。每个候选程序与自身的 `ce342df0` 基准逐轮比较，初次对角化和后续 16 轮的混合流，以及 16 轮的径向波函数，均逐字节一致。本批覆盖串行和单机 2 ranks。[P1 验收计划](../plans/plan-0004-f2018-follow-up-validation.md)

## 输入与对照

- 使用归档的 Zn I 价电子关联 AS1 输入 `e_mr_vv_as1.c`、核参数及 `e_mr_vv_as1.rwfn.inp` 初猜。30 个电子、17 个相对论亚壳层，四个偶宇称块按 J = 0、1、2、3 排列，各有 1,212、3,298、4,765、5,276 个 CSF，总计 14,551。rCSFs 4.1.0 生成的 V3 描述符 SHA-256 为 `e00af37adf67f149b43f8674f7842226f01f27cba2aa6f556003a268340580f5`。将 V3 恢复为 CSF 文本后，与原文件逐字节一致。对转换前后 17 个轨道独立解码，元数据、网格和 P/Q 全部相同。原生初猜 SHA-256 为 `19bdc80476185b5718b64e5f7597948a99cfd90439f3915a220a14f9b2b74df1`。
- 沿用锌-67 有限 Fermi 核、590 点网格、默认 SCF 选项。前 3 块各选根 1、2，第 4 块选根 1。统计权重归一化后为 (1, 1, 3, 3, 5, 5, 7) / 25。依次变化 `5s,4p,4p-,4f,4f-`，光谱轨道列表为空，迭代上限为 100。串行用完整相互作用生成 MCP，MPI 关闭零阶／一阶分区，为 2 ranks 生成索引分片。各构建从同一初猜独立启动，逐文件核对输入与相应 MCP 的摘要。
- macOS arm64，GNU Fortran 16.2.0、`f2018-release`（`-O2`）、LP64 OpenBLAS 0.3.34、Open MPI 5.0.11，每个进程的 BLAS 和 OpenMP 线程数均为 1。主对照为 `ce342df0` 与该提交上包含 RCI/Davidson 修复的工作树。候选 Fortran 源码补丁 SHA-256 为 `6d3b6e0888ad85116de1684489a4945f3a9d5cb07524ec06c5186faf8ad8f162`。另用所有权改造前的 `f493c993` 对照两个内存版。串行内存版在参与对照的构建中均使用同一处兼容改动，允许主机缺少 `/proc/meminfo` 时跳过系统内存打印。计量方法独立于这个诊断。[MCP 缓存](../../src/apps/rmcdhf_mem/cache_mcp_files.f90) · [来源清单](../reference/rmcdhf_optional_host_memory_snapshot.json)

## 逐轮收敛

从完整混合流读回每根双精度能量和系数，按块内绝对重叠匹配状态。径向流按 `(n, κ)` 和网格读回 P、Q。外部采集器只保存带完成签名的混合流及长度完整的径向流，另用迭代序号、根数、权重、逐根日志能量、文件数和末态摘要复核快照归属。[混合流读取器](../../test/mixing_stream.py) · [径向读取器](../../test/rmcdhf/compare_rwfn.py)

| SCF 轮次 | 加权总能量（Ha） | 相对上轮能量变化 | 最大轨道自洽误差 |
| ---: | ---: | ---: | ---: |
| 初次对角化 | −1794.4078629654 | — | — |
| 1 | −1794.4151971028 | — | 1.54e-2 |
| 4 | −1794.5644520348 | 6.97e-6 | 2.01e-2 |
| 8 | −1794.5667132689 | 1.21e-9 | 5.57e-4 |
| 12 | −1794.5667085437 | 2.36e-10 | 3.10e-5 |
| 15 | −1794.5667081923 | 2.60e-11 | 3.31e-6 |
| 16 | −1794.5667081703 | 1.22e-11 | 1.56e-6 |

表中精度下四个候选轨迹相同。程序在第 1 轮用零初始化上一轮加权能量。自第 2 轮起可比较相邻两轮。默认 `ACCY = 0.05⁶ = 1.5625e-8`。第 15 轮的相对能量变化仍高于 `0.001 × ACCY`，第 16 轮降至 `1.225e-11`，触发能量停止条件。此时最大轨道误差来自 `4p`，仍高于轨道停止阈值。四种程序均记录了正常结束。[串行停止条件](../../src/apps/rmcdhf/run_scf_iterations.f90) · [MPI 停止条件](../../src/apps/rmcdhf_mpi/run_scf_iterations_mpi.f90)

基准与候选另外各做了四次迭代上限为 1 的固定首轮计算。八次均由迭代上限停止，最终两份二进制流与对应正常收敛计算的第 1 轮逐字节一致。

同一变体与自身基准间，全部轮次的最大根能量差、相位对齐的混合系数差和径向 P/Q 差均为零。跨相邻轮次在同对称块内按重叠匹配，七根均能跟踪到原根，相邻轮次最小同根绝对重叠为 0.99558。各块内所有归一化和正交性检查中，Gram 矩阵相对单位阵的最大元素差为 5.11e-15。另与历史生产作业的末态比较，四种候选的最大根能量差为 1.82e-12 Ha，相位对齐后的最大混合系数差为 9.92e-11。

四种程序的基准与候选另做八次残差重放。在写出各块的混合向量前，用已装配的稀疏列独立累加对角项和两侧的非对角项。MPI 先对各 rank 的乘积求和，再用平移后的矩阵和本征值计算绝对残差 ‖Hc−Ec‖₂（Ha）。八次重放的全部混合流和径向快照均复现了对应原运行的字节内容。初次对角化加 16 轮、每次七根，共 952 个残差，逐项比较的基准与候选差为零。

最大残差出现在第 13 轮 J = 2 偶块第 2 根，串行两版为 9.41370e-10 Ha，MPI 两版为 9.41406e-10 Ha，均低于该块的 Davidson 残差容限 1e-9 Ha。第 16 轮的最大值为 5.29141e-10 Ha，对应 J = 3 偶块第 1 根。[串行块求解](../../src/apps/rmcdhf/diagonalize_hamiltonian_block.f90) · [MPI 块求解](../../src/apps/rmcdhf_mpi/diagonalize_hamiltonian_block_mpi.f90)

## 逐进程峰值 RSS

在四种原求解器的完整收敛运行中，每个 rank 的轻量父进程直接对求解器子进程调用 `wait4`。记录操作系统报告的 `ru_maxrss`、求解器 PID、rank 与退出码。Darwin 返回字节，下表除以 2²⁰ 得 MiB。MPI 数值按 rank 0、rank 1 排列。各计量运行依次执行。

| 程序 | 布局 | 基准峰值（MiB） | 候选峰值（MiB） |
| --- | --- | ---: | ---: |
| `rmcdhf` | 串行 | 170.72 | 171.39 |
| `rmcdhf_mem` | 串行 | 460.66 | 461.48 |
| `rmcdhf_mpi` | 2 ranks | 317.69 / 308.78 | 317.30 / 308.42 |
| `rmcdhf_mem_mpi` | 2 ranks | 462.19 / 454.94 | 461.67 / 454.94 |

改造前的 `f493c993` 也在第 16 轮结束。其串行内存版为 460.22 MiB，候选增加 1.27 MiB。其 MPI 内存版为 464.42 / 457.34 MiB，候选分别减少 2.75 / 2.41 MiB。每个版本、布局各测一次，单个进程的最大升幅为 1.27 MiB。这个量只给出该算例的进程高水位，无法据此定位小数组的分配或外推到更多 ranks。

与 `f493c993` 对照的两种内存版，在第 5 轮 J = 0 偶块第 1 根出现各自最大的能量差，串行为 1.91e-10 Ha，MPI 为 1.91e-10 Ha。全部轮次相位对齐后的最大混合系数差为 1.96e-7，同一根的绝对重叠均大于 0.99999999999996。该版本间还包括稀疏存储与 Davidson 收敛判定的更改，无法将差异单独归因于基组所有权。

## 本地复核

工作区 `temp/tests/zn-p1/` 保存冻结输入、SCF 应答和本批工具。`results/input-build-manifest.json` 记录输入、两种 MCP 布局、源码补丁和二进制摘要。`runs/<版本>-<程序>/` 下有原始日志、每个 rank 的退出记录、最终输出和逐轮快照。`results/` 下的 `scf.csv` 保存停止判据的轨迹，`roots.csv` 和 `orbitals.csv` 保存逐根、逐轨道数据，`rank-rss.csv` 保留原始字节数。Check 构建通过了 23 项 RMCDHF 专项回归，包括串行和 MPI 状态工作流、描述符输入、首轮比较、选根权重、阻尼与来源核对，详见 `logs/ctest-rmcdhf.log`。

`fixed/` 和 `results/fixed.json` 保存固定首轮结果。`probes/` 下的源码与 `replays/` 下对应的日志给出残差计算和原始数值。已有快照可从工作区根目录重新汇总。

```fish
set calculation temp/tests/zn-p1
env OPENBLAS_NUM_THREADS=1 graspkit-tools/.venv/bin/python "$calculation/analyze.py"
env OPENBLAS_NUM_THREADS=1 MPLCONFIGDIR="$calculation/tmp/mpl" graspkit-tools/.venv/bin/python "$calculation/extra_checks.py"
```
