# USE ONLY 第一批：单过程接口模块

日期：2026-11-17。基准为 HEAD `3e02e0f` 加未提交的 S1–S4 和五批风格修改。
本批收紧 USE 的书写范围，保留接口、数值精度和计算行为。

## 范围与选择依据

在普通 `rmcdhf`、`rmcdhf_mem`、`rmcdhf_mpi`、`rmcdhf_mem_mpi` 的外部程序单元中，
将 142 份文件的 524 条单过程接口模块导入改为显式 ONLY，例如：

```fortran
use convrt_i, only: convrt
use matrix_i, only: matrix
```

涉及 111 个模块名。候选提供者限于两种可核实结构：只声明一个外部过程的无名 INTERFACE
模块，或默认 PRIVATE 且仅 PUBLIC 一个过程的模块。存在多个同名模块提供者时，要求
它们的公开过程名一致。进一步核对修改前 380 份编译模块文件的导出符号表，确认新增 ONLY
列出的正是原来可导入的公开过程；编译器记录的模块自身标识不作为数据或过程实体统计。

本批保持全部原有 USE 语句，只显式列出原有公开过程，不删除未使用的导入、不改过程签名、
声明属性、变量、常量或调用。逐行验证只在所审阅的 USE 行添加 ONLY，物理行数不变。
共享状态模块、MPI 模块、带重命名的导入、模块级重导出以及复杂公开接口留待后续独立批次；
`parameter_def` 兼容重导出接口保持不变。

142 份导入 RMCDHF 文件追加
[USE ONLY 来源快照](../reference/rmcdhf_use_only_snapshot.json)，绑定 operator-style manifest，
历史快照不改。来源检查仍核对前驱及源码精确哈希。

## 验证

使用本机 Homebrew GNU Fortran 15.3.0，显式设置 FC/OMPI_FC；服务器工具链约定不变。
使用工作区共享 Python 和独立 Release/Check 构建目录。

- Fortitude C121 从 4,889 降至 4,365，减少 524；默认诊断从 8,945 降至 8,421。
- 扩展正确性检查从 16,377 降至 15,853；只减少本批 C121，其余规则按文件、行号和消息比较保持一致。
- 逐行检查确认修改仅为已审阅 USE 的 ONLY 列表，修改后文件哈希核对通过。
- Release/Check 全量构建通过。166 个受影响 Release 编译对象与前一批逐字节一致，
  全部 1,204 份编译模块文件解压内容一致，模块接口未变；多目标重复编译分别计数。
- 492 份导入文件来源检查及来源链篡改负例通过，包含源码及历史 manifest 的修改。
- Release/Check 两套完整 CTest 均一次性 89/89 通过；`git diff --check` 通过。

本地忽略目录 `build-use-only-20261117/` 保留修改前源码、文件哈希、每条导入及模块提供者清单、
编译器导出符号核对、静态诊断、对象/模块接口对照与构建/回归日志。
本批没有新增物理计算；既有科学验证范围与 macOS memory 完整 SCF 限制仍见
[S3/S4 报告](static_numeric_interfaces_2026-11-17.md)。没有提交、推送或安装覆盖生产二进制。
