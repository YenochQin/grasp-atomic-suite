# USE ONLY 第二批：其他应用的单过程接口

日期：2026-11-17。基准为 HEAD `3e02e0f` 加此前未提交修改，接续
[USE ONLY 第一批](use_only_interfaces_2026-11-17.md)。本批保持接口、数值精度和计算行为。

## 修改范围

在 15 个非 RMCDHF 应用目录的 275 份文件中，为 906 条 USE 补充 ONLY：

| 应用目录 | 导入数量 |
| --- | ---: |
| gj | 33 |
| jj2lsj | 2 |
| rangular / rangular_mpi | 33 / 28 |
| rbiotransform / rbiotransform_mpi | 74 / 70 |
| rci / rci_mpi | 117 / 122 |
| rdensity | 17 |
| rhfs | 51 |
| ris4 | 110 |
| rtransition / rtransition_mpi / rtransition_phase | 69 / 69 / 69 |
| rwfnestimate | 42 |

只处理外部程序单元中未带重命名、仅公开一个过程的 `_i` 模块导入。
候选模块必须是单过程无名接口块，或默认 PRIVATE 且只 PUBLIC 一个过程的模块；
所有同名源码提供者须一致。修改前进一步核对 568 份编译模块文件，覆盖 247 个模块名，
确认导出过程集合与 ONLY 列表一致。编译器记录的模块自身标识不作为数据/过程实体统计。

原有 USE 全部保留，仅补充 ONLY，不删除未使用导入，不改签名、变量、常量、调用和数值表达式。
逐行验证修改范围，物理行数保持不变，没有新增超长行。模块级重导出、共享状态、MPI、
泛型和复杂公开接口不在本批范围。四种 RMCDHF 及其来源快照保持上一批状态。

## 验证

使用本机 Homebrew GNU Fortran 15.3.0，显式设置 FC/OMPI_FC；服务器工具链约定不变。
Python 使用工作区共享环境，构建位于独立 Release/Check 目录。

- Fortitude C121 从 4,365 降至 3,459，减少 906 条；默认诊断从 8,421 降至 7,515。
- 扩展正确性检查从 15,853 降至 14,947；差异恰为本批 906 条 C121，其余诊断按文件、
  规则、行号和消息比较完全一致。
- 修改后逐文件哈希核对通过；既有 492 份导入 RMCDHF 文件的来源检查通过。
- Release/Check 全量构建通过。312 个受影响 Release 编译对象逐字节一致；全部 1,204 份
  编译模块文件解压内容一致，接口未变。多目标重复编译分别计数。
- 四份修改源码未列入当前 CMake 目标：`rbiotransform/ichkq1.f90` 及三个 `rtransition*`
  目录的 `setcsl.f90`。用各自应用的编译参数补做修改前后编译，四对对象全部逐字节一致；
  此检查不将这些源码登记为新的应用入口，也不证明未构建入口的运行覆盖。
- Release/Check 两套完整 CTest 均一次性 89/89 通过；`git diff --check` 通过。

本地忽略目录 `build-use-only-apps-20261117/` 保存修改前源码、文件哈希、每条导入和模块
提供者清单、编译器导出符号核对、静态诊断、对象/模块接口对照与构建/测试日志。
没有新增物理计算；既有科学验证范围和 macOS memory 完整 SCF 限制仍见
[S3/S4 报告](static_numeric_interfaces_2026-11-17.md)。未提交、推送或安装覆盖生产二进制。

剩余 3,459 条 C121 需继续按实际符号依赖、重命名、泛型及重导出契约逐批处理；
不能仅依据局部文本中的符号出现次数删减导入。
