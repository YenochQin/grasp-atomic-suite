# USE ONLY 第三批：共享库内部过程导入

日期：2026-11-17。基准为 HEAD `3e02e0f` 加此前未提交修改，接续
[其他应用接口整理](use_only_app_interfaces_2026-11-17.md)。本批保持接口、数值精度和计算行为。

## 修改范围

115 份文件补齐 396 条 ONLY，按共享库分布如下：

| 目录 | 导入数量 |
| --- | ---: |
| lib9290 | 59 |
| libdvd90 | 15 |
| libmcp90 | 1 |
| librang90 | 312 |
| mpi90 | 9 |

继续限定为仅公开一个过程的 `_i` 模块，无名接口块仅声明一个过程，或默认 PRIVATE
且仅 PUBLIC 一个过程；同名源码提供者须一致。修改前核对 171 份编译模块文件，覆盖
133 个模块名，公开过程与 ONLY 列表一致。模块自身标识不作为数据/过程实体统计。

对于含模块的文件，仅修改 CONTAINS 之后的过程内 USE，模块头部重导出不动；
多个模块或没有 CONTAINS 的文件跳过。独立外部过程同样按单过程导出范围处理。
原有 USE 保留，不删除导入、不改签名、变量、常量、调用和数值表达式。
逐行验证只添加审阅过的 ONLY 列表，物理行数不变，没有新增超长行。
共享状态、MPI 全量接口、泛型及复杂重导出留待后续。

## 验证

使用本机 Homebrew GNU Fortran 15.3.0，显式设置 FC/OMPI_FC；服务器工具链约定不变。
Python 使用工作区共享环境，采用独立 Release/Check 构建目录。

- Fortitude C121 从 3,459 降至 3,063，减少 396 条；默认诊断从 7,515 降至 7,119。
- 扩展正确性检查从 14,947 降至 14,551；差异恰为本批 396 条 C121，其余诊断按文件、
  规则、行号和消息比较完全一致。
- 115 份文件修改后的哈希及逐行编辑范围核对通过；既有 492 份导入 RMCDHF 来源检查通过。
  RMCDHF 应用源码和来源快照本批未改动。
- Release/Check 全量构建通过；128 个受影响 Release 编译对象逐字节一致，全部 1,204 份
  编译模块文件解压内容一致，模块接口未变。115 份修改源码均列入当前构建目标，
  多目标重复编译分别计数。
- Release/Check 两套完整 CTest 均一次性 89/89 通过；`git diff --check` 通过。

本地忽略目录 `build-use-only-libs-20261117/` 保存修改前源码、文件哈希、每条导入及模块
提供者清单、编译器导出表、静态诊断、对象/模块接口对照与构建/测试日志。
没有新增物理计算；既有科学验证范围和 macOS memory 完整 SCF 限制仍见
[S3/S4 报告](static_numeric_interfaces_2026-11-17.md)。未提交、推送或安装覆盖生产二进制。
