# 辐射跃迁的选择定则、弱线与相位

2026-11-27，以 Suite `5a664b58` 为基准，核对本批工作树的 `rtransition`、`rtransition_mpi` 和 `rtransition_phase`。单电子夹具从双正交变换运行到最终谱线报告。仓库 Ni I 夹具另用同一套轨道和九个多电子态检验 M1、E2。构建环境为 macOS arm64、GNU Fortran 16.2.0、Open MPI 5.0.11 和 OpenBLAS 0.3.34（LP64）。Check 启用运行时及浮点异常检查，Release 使用 -O2。MPI 使用两个 rank，BLAS 和 OpenMP 各一个线程。[生产入口回归](../../test/test_radiative_transitions.py)

## 单电子对照

左态包含 1s、2s 两个偶宇称 CSF 和一个 2p₁/₂ 奇宇称 CSF，右态为 2p₃/₂。径向大分量取氢样函数，小分量取动能平衡近似 Q = (dP/dr + κP/r)/(2c)，在 H = 0.05、RNT = 2e−6 的 590 点网上联合归一化。两个偶宇称根赋予相同的能量，使两条 E1 振幅能在同一频率下线性组合。E1、M1 的参考能差分别为 0.375、0.005 Ha。相位约定固定为初始纯 CSF 和末态系数均取正。

各侧独有的 κ 组无需旋转，因而可用原始径向流和混合流直接构造恒等变换对照。基准通过这一路径计算，候选从实际的串行或 MPI 双正交入口生成全部输入。表中列出 2p₃/₂ 向低能态辐射的结果。M 为 phase 入口给出的带符号约化矩阵元，电偶极线强以原子单位计，磁偶极线强以 μB² 计。

| 低能态 | 多极与规范 | 能差（Ha） | A（s⁻¹） | 线强 S | M |
| --- | --- | ---: | ---: | ---: | ---: |
| 1s | E1 Coulomb | 0.375 | 6.26806e8 | 2.21963 | +1.48984 |
| 1s | E1 Babushkin | 0.375 | 6.26815e8 | 2.21966 | +1.48985 |
| 2s | E1 Coulomb | 0.375 | 0.703764 | 2.49215e−9 | +4.99214e−5 |
| 2s | E1 Babushkin | 0.375 | 1.01652e10 | 35.9965 | −5.99971 |
| 2p₁/₂ | M1 | 0.005 | 0.0118816 | 1.33332 | +1.15470 |
| 1s、2s 的相消组合 | E1 Babushkin | 0.375 | 5.43874e3 | 1.92595e−5 | +0.00438856 |

在长波近似下，1s、2s 的长度规范约化偶极分别为 d₁ = √(4/3) × 256/(81√6) 和 d₂ = −6。弱线取归一化系数 (−d₂, 0.997 d₁)，使两项接近相消。运行所得 Babushkin 线强约为纯 1s 对照的 8.68e−6；同一组合的 Coulomb 线强为 2.09148。人为指定的 2s 能差用于检验算符收缩，两个规范各自与固定输入基准比较。两条纯态长度规范线强及 M1 的 LS 极限 4/3 使用 2e−4 的相对容差。固定频率线性叠加的弱振幅使用 6e−6 的绝对容差，以容纳分量报告只保留六位有效数字的舍入。

- 改变末态整体相位后，phase 报告中的 E1 两规范和 M1 矩阵元均反号，A、gf、S 保持相同。互换初末文件恢复了相同的上、下能级与谱线数值。
- 保持轨道和系数，分别将两类能差减半。每条线按自身重算的 S 验证 A/S 随 |ω|³ 变化、gf/S 随 |ω| 变化。例如 1s 的 Babushkin 跃迁率从 6.26815e8 降至 7.83532e7 s⁻¹。单独核对规范、统计权重和磁偶极换算后，率与线强关系的相对容差为 1.5e−5。
- E1 排除了同宇称的 2p 对，M1 排除了宇称相反的 s、p 对。E3 输入允许 s、p 的宇称变化，却因 J 的三角条件无谱线。另把两个不同文件的 2p 态设为严格等能，候选跳过该零频 M1 对并保留其余 E1 线。

对强线、弱线、半能差、相位翻转、文件互换分别冻结输入。三种入口 × 两种构建 × 五种情形，共 30 组对照；在报告精度下，能量、A、gf、S 及 phase 的符号列逐项相同。

## Ni I 多电子对照

使用仓库的 28 电子、16 轨道、1,042 个 CSF，J = 0 至 4 的五个偶宇称块分别有 2、1、3、1、2 根。初末态取同一基组及混合流，在该共同基组上直接运行三个跃迁入口。每份报告有 14 条 M1 和 25 条 E2，E2 各给出两种规范。Check 和 Release 共六份默认报告逐字节等于同构建、同入口的基准。跨串行和双 rank 的共有数值字段在报告精度下相同。[Ni I 基组](../../data/test_header.toml) · [能级表](../../data/test.level)

例如 J = 3 第 1 根至 J = 4 第 1 根的能差为 1379.17 cm⁻¹，M1 跃迁率为 0.0681481 s⁻¹，带符号矩阵元为 −2.59645。E2 的 Coulomb、Babushkin 跃迁率分别为 6.06554e−8 和 3.03212e−10 s⁻¹。只选择不同 J 后，候选精确保留原 64 行中的 52 行，同 J 的 12 行被排除。

## 复现的故障与修复

| 输入 | 基准表现 | 候选表现 |
| --- | --- | --- |
| 初末态没有共同 κ 组 | 双正交入口跳过该组的旋转矩阵初始化，Check 串行在 CI 补偿时触发浮点异常 | 单侧轨道和 CI 补偿均用单位矩阵，串行及双 rank 流水线复现恒等变换对照。 |
| 不同态文件、精确零能差 | 三个 Check 入口均异常退出；Release 返回 0 并报告无效浮点运算和除零标志 | 在生成径向核及逆频率因子之前跳过该对。 |
| 换入仅初态两行 CSF 顺序不同的同维度 E1 角缓存 | 错把第 2 根的 Babushkin 线强 35.9965 赋给第 1 根，其参考值为 2.21966 | 核对有序的两个基组摘要、多极、J 筛选、进程数、rank 和完成记录。只重算不匹配的分片。 |
| 使用相同文件名，将 M1/E2 改为只许不同 J | 复用已有缓存留下 12 行非零的同 J 结果；用旧程序冷算则留下 12 行零值 | 筛选同时作用于 CSF 角系数和待写出的能级对。串行与 MPI 升级真实旧缓存后均保留 52 行，其值与未筛选对照逐项相同。 |

可复用角文件保持原文件名。旧格式或截断文件在下一次使用时重算；关闭保存时，新生成的记录使用临时文件。格式检查覆盖来源、布局、首块头与写入完成标记，角系数载荷没有逐字节校验和。[角缓存实现](../../src/lib/core/transition_angular_cache.f90) · [单侧轨道组处理](../../src/apps/rbiotransform/transform_orbital_sets.f90)

## 复验

从 Suite 根目录运行以下命令。构建须启用对应目标和 V3 夹具生成器。工作区 `temp/tests/tr-p1/` 中的 `frozen-final/`、`comparison.json` 保存单电子逐组冻结输入、输出及比较；`ni-final/`、`ni-summary.json` 保存 Ni I 的六组新旧报告。`cache-upgrade/` 和 `cache-summary.json` 保存实际旧版角文件切换筛选后的复现。

```fish
set -gx TMPDIR (realpath ../temp/tests)
for profile in check release
    ctest --test-dir "../temp/tests/rci-p1/$profile" --no-tests=error --output-on-failure \
        -R 'radiative_transitions|biorthogonal_states|bndinv|dual_basis_pipeline|f2018_.*source_style'
end
```

Check 和 Release 各通过 12 项定向测试。本批验证默认 Kays 能量单位下的主报告，涵盖 E1、M1、E2 的非零谱线和 E3 角动量禁戒。更高多极的非零矩阵元、活性空间物理收敛及部署环境完整矩阵另行验收。[P1 后续计划](../plans/plan-0004-f2018-follow-up-validation.md)
