# 双正交变换的单电子态与角缓存验收

2026-11-27，以 Suite `5e2320a8` 为基准，对照本批工作树的 `rbiotransform` 和 `rbiotransform_mpi`。四种合法布局均保持了单电子态。基准串行程序复用同维度错误基组的角缓存时，轨道交叉重叠仍满足双正交条件，但单位算符矩阵元偏差达到 0.126。候选程序识别该缓存并重算，恢复了冷启动的输出。[生产入口回归](../../test/test_biorthogonal_states.py) · [共享缓存实现](../../src/lib/core/biorthogonal_angular_cache.f90)

## 夹具和判据

取氢样 1s、2s 归一化径向函数。右态的两个轨道分别取左态的线性组合 `0.8 × 1s + 0.6 × 2s` 和 `−0.6 × 1s + 0.8 × 2s`。在两侧都令小分量 Q = 0.05P，并对两分量联合归一化。程序从 V3 描述符、径向流和混合流读取每态的一个 J = 1/2 偶宇称根。在双轨道侧，依 CSF 顺序给定混合系数 (0.8, 0.6)，单轨道侧为 1。有限核网格为 590 点，H = 0.05，RNT = 2e−6。

独立读取四份变换输出。在均匀对数坐标上积分 P 和 Q，比较交叉重叠与矩形单位阵。用变换前后各自的混合系数重建波函数，逐网格点比较 P、Q；再与已知轨道旋转给出的跨态单位算符矩阵元对照。混合流另核对来源描述符的 SHA-256、块 J、宇称、CSF 数、根编号和能量。基准的三个最大绝对偏差均低于 2e−14；为该解析夹具采用 1e−10 的绝对回归上限。[径向读取器](../../test/rmcdhf/compare_rwfn.py) · [混合流读取器](../../test/mixing_stream.py)

## 冻结输入的结果

本机为 macOS arm64、GNU Fortran 16.2.0、Open MPI 5.0.11 和 OpenBLAS 0.3.34（LP64）。分别使用 F2018 Check（含边界与浮点异常检查）和 Release（-O2），在串行、2-rank MPI 两种布局上用同一份输入重放。下表为候选在四种配置中的最大绝对偏差，数值按三位有效数字列出。

| 初态、末态的轨道顺序 | 交叉重叠矩阵元素 | 重建波函数 P/Q 分量 | 单位算符矩阵元 |
| --- | ---: | ---: | ---: |
| (1s, 2s)、(1s, 2s) | 4.44e−16 | 1.85e−14 | 9.99e−16 |
| (2s, 1s)、(2s, 1s) | 4.44e−16 | 1.85e−14 | 9.99e−16 |
| (1s, 2s)、(1s) | 3.33e−16 | 1.87e−14 | 6.66e−16 |
| (1s)、(1s, 2s) | 3.33e−16 | 1.66e−14 | 5.00e−16 |

4 种布局 × 2 个构建 profile × 2 种运行方式，共 16 组合法基准与候选对照。每组初末态各一份 `.bw` 和 `.bm`，64 对文件逐字节相同。固定同一 profile 时，串行与双 rank 的输出也逐字节相同。

## 失败与缓存

| 输入或故障 | 实测结果 |
| --- | --- |
| 初末态一个正序一个逆序、两侧同为 (2s, 1s, 3s)、末态两轨道线性相关 | 基准串行三例均返回 0。基准 MPI 由启动器报告非正常结束。候选串行与 MPI 均报告相应原因、返回 1，干净工作目录中未生成变换流。全零重叠方块另由两个求逆单元测试覆盖。 |
| 互换同维度基组的两行 CSF，将该态生成的角缓存复制给原输入 | 基准误用缓存后，重叠偏差仍为 4.44e−16，重建波函数最大分量偏差为 0.08301665。候选只重算错误分片，四份输出均与冷启动逐字节相同。 |
| 旧版本生成的缓存、截断文件尾、错误块头、MPI 分片放错 rank | 候选重算受影响的分片。用基准实际生成的旧缓存重放后，再次运行命中新格式缓存。 |
| 缩小 J 选择、切回全部 J、读取 CI 混合流、关闭角文件保存 | 各 rank 收到相同的 J 选择并按选择重建缓存。CI 夹具的 `.cbm` 与相同输入向量的 `.bm` 相同。无已有缓存且关闭保存时，临时角记录能完成补偿，运行后无 `.TB`。两侧 J 计数越界的输入均被拒绝。 |

缓存末记录包含格式标识、当前描述符 SHA-256、维数、κ 分组、所选 J 和进程布局，写完角记录后才追加。读取同时校验首块维数。该格式校验覆盖身份和文件是否写完；角系数载荷没有逐字节校验和。MPI 的共享 `.bw` 现在由 rank 0 写出，基准双 rank 日志中初末态各有两次写出，候选各有一次。[MPI 主程序](../../src/apps/rbiotransform_mpi/rbiotransform_mpi_main.f90)

## 复验与范围

从 Suite 根目录对已配置的构建运行下列命令，可重放单电子夹具及相关回归。在工作区 `temp/tests/bio-p1/` 下，`profiles/` 按 profile、基准或候选、运行方式及夹具保存冻结输入、二进制输出和日志；`comparison.json` 保存逐组数值与字节比较，`base-donor/` 和 `base-recipient/` 保留修复前的错缓存复现。

```fish
set -gx TMPDIR (realpath ../temp/tests)
for profile in check release
    ctest --test-dir "../temp/tests/rci-p1/$profile" --no-tests=error --output-on-failure \
        -R 'biorthogonal_states|bndinv|dual_basis_pipeline|f2018_.*source_style'
end
```

Check 和 Release 各通过上述 9 项测试，包括既有的串行与 MPI 双基组跃迁流水线。单位算符检验覆盖双正交变换及混合系数补偿。辐射允许线、禁戒线与弱线的矩阵元、电多极两规范及相位符号仍列在下一批。[后续验收计划](../plans/plan-0004-f2018-follow-up-validation.md)
