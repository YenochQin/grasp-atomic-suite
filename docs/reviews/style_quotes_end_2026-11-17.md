[第一批风格整理](style_spacing_2026-11-17.md)。本批不改变计算表达式、数值精度或接口。

共修改 1,287 份 Fortran 文件。仅应用这两条规则中标记 safe 的编辑，整份跳过
E001 文件，不运行全仓库自动修复。引号编辑只替换定界符；逐文件解码字符串后比较，
确认字符内容、其他代码和注释一致。END 编辑补充程序单元种类及名称，交由编译器核对。
物理行数不变，没有新增超过 132 列的行。

剩余 456 条引号和 4 条 END 提示在解析问题文件中；另 2 条引号提示位于
`src/lib/lib9290/radgrd.f90` 的 FORMAT 字符串，含重复单引号转义，工具未提供安全修复，
本批保留。没有把未处理项隐藏或写成已经解决。

362 份导入 RMCDHF 文件追加
[quote/end 来源快照](../reference/rmcdhf_quote_end_snapshot.json)，绑定 spacing manifest。
历史快照不变，来源检查仍逐文件验证精确哈希。MPI 输出测试的源码提取器同时支持
具名 END 和两种引号，仍要求恰好一个输出路径，保留原来的运行行为断言。
入口检查及环境变量 helper 的提取器也支持两种引号或具名 END，检查的路径、调用参数、
精度和运行结果不变。

## 验证

GNU Fortran 15.3.0，FC/OMPI_FC 显式使用本机 Homebrew GNU 15；仓库的服务器路径约定未改。
Python 使用工作区共享环境，构建位于独立 Release/Check 目录。

- Fortitude 默认诊断从 26,547 降至 11,567，恰好减少 14,980 条。
- correctness/portability/obsolescent/error 加 preview 的 16,377 条诊断，按文件、规则、行号和消息比较完全一致。
- 492 份导入文件来源检查通过；源码以及 declaration、numeric-kind、spacing 历史快照的篡改负例均被拒绝。
- Release/Check 全量构建通过。两套 CTest 首轮各 87/89 通过，两个失败均为测试脚本
  对旧引号或裸 END 的精确匹配；调整提取器后，两套定向复测均 2/2 通过，合计各 89 项通过。
- 对照上一批 Release 构建，1,461 个受影响编译对象中 1,279 个逐字节一致；另外 182 个
  长度相同，全部差异仅为 `__const` 区的 2,552 个单引号字节变为双引号。
  对这些常量片段解码比较，438 处格式文本内容等价；指令和其他对象字节不变。
  无当前编译对象的源码文本不计入对象比较。
