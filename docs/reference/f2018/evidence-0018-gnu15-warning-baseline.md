# GNU Fortran 15 历史告警基线

GNU Fortran 15.3.0 时期采集了 24 个诊断配置，包括当时的 rangular OpenMP 组合。
机器可读记录保留源文件哈希、各配置的编译覆盖、逐目标诊断和后续预算调整。
历史源码路径对应当时的目录结构。[GNU 15 JSON](gfortran15-warning-baseline.json)
