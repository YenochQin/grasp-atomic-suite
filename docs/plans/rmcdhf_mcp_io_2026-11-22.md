2026-11-22，源码基准为 Suite `c1377aa0`。阶段 0–2 已完成本地验收。根据 `3.4dev1` 开发要求，现行 MPI 计算链直接使用带目录格式，
A、B 对照使用归档基线。MPI 内存版已接入共享读接口。
见[当前计算链、格式和本地结果](../implemented/rmcdhf_mcp_io.md)。

2026-11-23，阶段 3 已完成作业 14 的 A/C 目标文件系统对照。冷、热缓存下全 SCF 墙钟均改善，
冷态全 SCF 实际读盘量增加。势系数分段探针已在两份独立基准快照中通过本地校验，
分段生产测量和单 rank 内存预算核对待完成。[实测、验收差距与复跑](../reviews/rmcdhf_mcp_phase3_2026-11-23.md)

以下保留原始实施计划和 A/B/C 验收定义。首个交付对象为普通 `rmcdhf_mpi` 的 EOL 路径及配套 `rangular_mpi`。目标是在一次混合系数和密度权重更新之后，每个 MPI rank 为势系数至多读取一次相关稀疏结构和积分组，避免按轨道和多极阶反复扫描 MCP。矩阵仍用当前径向积分和角系数装配。旧格式与旧计算路径在验证期间保留可选入口。[容量与访问路径分析](../reviews/rangular_mcp_io_2026-11-22.md#从-rmcdhf-的访问方式设计-mcp)

## 阶段 0　记录旧路径基线，核定计数和内存

1. 在 `rmcdhf_mpi` 分别记录矩阵装配、势系数构造、径向势计算和 MPI 归约的墙钟。每 rank 记录读取的结构块数、读取或跳过的积分组数、贡献条数、字节数和调用轨道。势系数调用按相邻两次混合系数及权重更新分组，覆盖乘子调用、普通轨道更新、追加更新和失败重试。[SCF 循环](../../src/apps/rmcdhf_mpi/run_scf_iterations_mpi.f90#L159) · [乘子两侧的访问](../../src/apps/rmcdhf_mpi/calculate_lagrange_multipliers_mpi.f90#L141)
2. 用同一输入记录各 `J^pi` 块、rank 和通道的稀疏位置数、组数、贡献数、最大组和最大通道。分别估算紧凑结构、组描述符与收缩结果、排序及求解工作区的峰值内存。选用现有小样本作为正确性基线，在目标存储上另取一个含多个大块、会重复构造轨道势的代表算例。[现有 MCP I/O 回归](../../test/f2018/check_mcp_io.py) · [现有 MPI 采样说明](../implemented/rmcdhf_mpi_diagnostics.md)
3. 独立修正三角位置数的乘法和全块非零数的 MPI 归约，使用 64 位统计。核查生成和读取端的位置、文件内计数及排序下标。旧字段或下标装不下的输入须在写入越界或错误计数前明确失败。带目录格式的大记录能力在阶段 2 单独按真实字段和分段规则验收。[现有统计类型](../../src/apps/rangular_mpi/write_mcp_sparsity_summary_mpi.f90#L25) · [排序下标](../../src/apps/rangular_mpi/sort_mcp_coefficients.f90#L154)

**验收**。小样本的 I/O 计数和二进制记录逐块吻合。以超过 32 位三角数的合成计数验证统计，无需构造对应的大矩阵。生产基线保留 rank 间读写和等待时间的分布，以便区分实际读盘、其他 rank 等待归约以及内存回收。

## 阶段 1　沿用现有 MCP，实现一次流式收缩

1. 在 `update_scf_mixing_mpi` 完成之后开始新的收缩缓存周期。缓存归当前计算和 MPI rank 所有，在首次需要势系数时构造。下一次混合系数、能级权重或轨道广义占据数更新后使缓存失效。EAL 初期继续走已支持的路径。[权重与占据更新](../../src/apps/rmcdhf_mpi/update_scf_mixing_mpi.f90#L55)
2. 从旧 `mcp.30` 一次加载各块紧凑稀疏索引，在一遍系数扫描中复用。根据可优化轨道及当前乘子分支实际可能访问的轨道，选取所需积分组。首版涵盖现有乘子代码可能访问的冻结侧及后续才选定的追加更新轨道。对每个 `(块、通道、标签)`，沿原贡献顺序累加密度矩阵元乘角系数，保留对角与非对角的权重规则。缓存每组收缩和及必要目录信息，记录 `.30` 缓存和收缩表在每个 rank 的实际字节数。[一电子收缩](../../src/apps/rmcdhf_mpi/assemble_orbital_potential_coefficients.f90#L305) · [二电子收缩](../../src/apps/rmcdhf_mpi/assemble_orbital_potential_coefficients.f90#L467)
3. 复用原有按轨道生成 DA、YA、XA 的逻辑。把每组收缩和代入旧路径的归一化、标签位置判断和跨块累加。保留一电子块顺序和二电子 `k → 块 → 标签` 的次序，保持隐式对角项、乘子和 MPI 归约原有运算位置。径向网格势仍以当时的径向函数计算。矩阵装配继续通过现有入口，并使用与势系数扫描独立的文件定位状态。
4. 以显式运行选项启用试验路径。缓存内存按 rank 预算，并计入当前求解工作区。若整套结构或收缩表超出预算，在进入试验读取前由所有 ranks 一致选择旧路径，并记录原因。阶段 2 再用按块读取把结构驻留限制在当前块；组表仍按实测容量核算。

**验收**。同一编译器、配置、输入、rank 数和归约顺序下，逐组比较收缩和，逐轨道比较 DA、YA、XA 的标签、次序与值。保持相同浮点操作的路径以逐位比较为目标。再比较矩阵、乘子、径向势、各轮能量、轨道及收敛状态。读计数应显示，同一次密度权重更新内重复请求一个轨道时没有再次读取已覆盖的系数，下一次更新时重新收缩。缓存预算不足时各 rank 一致使用旧路径。

## 阶段 2　rangular 写出带目录的 MCP，RMCDHF 按块读取

1. 先完成 MPI 使用的共享 MCP 读写接口。试验格式按 rank 各写一个二进制流文件，物理顺序为 `块 → T、V(0)…V(Kmax) → 积分标签`。每块先存紧凑列终点和行号，再存该块的积分组。复用当前稀疏结构和积分分组写出点，随写入记录组偏移、长度、标签和贡献数。索引从积分标签取得相关轨道，使同一份贡献可用于矩阵和各个轨道。长积分组允许连续分段，保留原始浮点位模式和贡献次序。[稀疏写出](../../src/apps/rangular_mpi/write_mcp_sparsity.f90#L85) · [积分分组写出](../../src/apps/rangular_mpi/sort_mcp_coefficients.f90#L223)
2. 头部规定版本、端序、整数与浮点表示、标签基数、轨道和 CSF 顺序的基组标识、rank 布局及各块相互作用分区。将偏移、长度和计数定义为显式 64 位。若采用 32 位块内贡献位置或列号，对每个 rank 和块检查界限，并在格式中明确其宽度。用有界缓冲处理大组。写完目录并完成所有 rank 的一致性检查后再标记产物完整；读取前检查格式、基组、rank 数及各分片身份，截断或不匹配时走集体错误路径。[现有 rank 布局校验](../../src/apps/rmcdhf_mpi/connect_mcp_files.f90#L102)
3. 用同一目录驱动两条读取路径。矩阵装配按选择的块连续读，跳过未选根块的数据时保留现有求解和输出所需的块状态。收缩路径在一个块内读取所需组的并集，复用本块索引。读取顺序可以按磁盘排列，缓存后的结果按阶段 1 的运算顺序构造各轨道系数。相邻组可合并读取，分别统计命中条数和实际读取的附加字节。[未选根块的现有处理](../../src/apps/rmcdhf_mpi/solve_hamiltonian_blocks_mpi.f90#L136)
4. 生成端通过显式选项选择一种输出，每次只写一套 MCP。读取端也显式选择试验格式，读取失败应报告该格式的错误。旧文件原样用于对照和回退。批量临时记录、有界外部归并排序、无损压缩和省略冗余列号另行测量，依据写入峰值、组分布和读盘收益决定接入顺序。

**验收**。用旧格式和新格式算同一基组，逐块对照稀疏结构、原始组顺序和贡献位模式，再用两个格式分别走相同 SCF 对照。覆盖未选根块、空 rank、空通道、跨分段的大组、偏移超过 32 位、基组或 rank 不匹配、截断分片。每次密度更新中，一个实际需要的积分组在一个 rank 上只由一次收缩扫描消费。矩阵阶段跳过的块以读取计数核实。

## 阶段 3　目标文件系统对照与发布

现行开发分支使用路径 C。A/C 的目标文件系统对照与待办见[阶段 3 实测记录](../reviews/rmcdhf_mcp_phase3_2026-11-23.md)。
下表保留原始 A/B/C 设计，用于归档比较。

| 对照路径 | 用于回答 |
| --- | --- |
| A．旧 MCP 与旧 RMCDHF 路径 | 每次势系数调用到底读了多少，哪些 rank、哪些阶段出现等待 |
| B．旧 MCP 与一次流式收缩 | 仅改变读取频率和收缩复用能减少多少 I/O 及 CPU 等待 |
| C．带目录 MCP 与一次流式收缩 | 直接跳块、按需读取和块内结构复用带来多少增量收益 |

- 用相同基组、交互分区、目标根、冻结列表、初始轨道、SCF 参数、MPI 布局和文件系统重复测量。记录冷／热缓存条件，分别比较最慢 rank 和全部 ranks 的读取字节、等待时间、每轮 SCF 墙钟、峰值 RSS、生成峰值磁盘和最终文件大小。
- 先通过组收缩、矩阵及 SCF 数值对照，再比较性能。生产验收要求代表性重复读取作业的势系数阶段实际读量和最慢 rank 墙钟可重复下降，整个 SCF 墙钟随之改善，并符合单 rank 内存预算。对 C 路径额外核算生成成本和成果的复用次数，再决定是否切换默认值。基线尚无设备计数，因此性能指标用固定条件下的实测对照确定。
- 普通 MPI 验收通过后，再评估串行 `rangular`、`rmcdhf` 和两种内存版接入共享读取接口。每个变体与自身旧路径比较，覆盖原有输入和求解选项，再决定开放范围。构建和计算验证使用工作区 `temp/tests/`，生产文件系统基准保留在目标作业的独立目录。[V3 计算链回归入口](../../test/CMakeLists.txt#L138) · [GNU Fortran 构建与验收](../implemented/build_profiles.md)
