## 已关闭的旧任务与保留例外

- RIS4 缓存、JJ2LSJ 唯一标签读取、限定实常量精度及接口防御性修复已实施于 `bea6655`。
- USE ONLY 完成于 `5806884`。当时 C121 剩一条：`mpi_c` 公开转发 MPI 符号的
  模块级 `use mpi`；保留此接口，不把它列为尚未完成的批量改写。
- `8cf6b1d`、`80f6e76` 已完成原生 CSF 输入迁移。旧 `lodcsh`、
  `lodcsl` 及三份 `lodcslm` 的文本 reader 风险不再作为当前生产入口待办；
  新路径及验收边界见[原生描述符说明](../implemented/native_csf_descriptors.md)。

## 继续核定的范围

| 方向 | 后续要求 |
| --- | --- |
| INTENT、模块可见性、公开可变状态 | 按实现、调用链、别名和错误路径核定；先列出现行公开 API 与重导出，不批量猜测 IN/OUT 或 PRIVATE。 |
| 外部过程、回调、数组与字符接口 | 区分外部 ABI、测试替身、假定大小数组和字符长度契约，保持接口及边界一致。 |
| I/O 单元与错误信息 | 核查固定单元号、OPEN ACTION、IOMSG/ERRMSG、部分分配及清理路径；保留原错误状态和 MPI 失败传播。 |
| NP 状态检查 | 旧提示涉及原错误保留、受保护读取及 INQUIRE；按当前调用链复核，不把所有 C181 判成错误输入接受。 |
| 旧式内建函数、带标签循环、GO TO | 检查 kind、绑定、跳转目标与运算顺序；不可达分支清理不等于新增重启或其他功能。 |
| 遮蔽、缺省分支、固定容量与可读性 | 依据实际契约分批处理，不将规范提示数量充作真实缺陷数量。 |
| 历史编译告警预算 | 按当前源码、目标和 GNU 15 配置复核覆盖及诊断身份；不自动放宽预算。 |

## 尚缺的数值验证

S1–S4 没有新增完整 RIS4 物理结果对照；当时 memory 完整 SCF 对照受 macOS
缺少 `/proc/meminfo` 限制，需在支持平台按原输入续做。
普通小夹具通过与 Ni/Zn 初猜末位变化均不证明一般体系的物理收敛。
具体实验位置和限制见[兼容性说明](../implemented/f2018_compatibility.md#验证入口与边界)；
原生输入验收不能自动替代针对常量精度修复的独立对照。

## 接续工作与验收

1. 阅读仓库规范，核对 HEAD、工作树和受影响的编译/预处理上下文，重新扫描后再确定每批范围。
2. 先核定真实缺陷、规范建议和工具限制；不全仓库自动修复，不通过放宽编译检查或数值容差获得通过。
3. 检查符号绑定、重导出与公开接口。按影响运行 GNU 15 Release/Check、
   串行/MPI 回归；格式修改检查输出字节，数值修改报告预期及实际差异。
4. 保留来源快照链，更新实际尚未完成的事项。历史测试结果不能继承为新改动的验证。
5. 科学实验事前说明目的、输入与对照；提交、推送和集群作业按用户当时授权执行。
