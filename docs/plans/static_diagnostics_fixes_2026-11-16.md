## 3. 下一批建议与验收

### S1：RIS4 角向缓存（P2，已复现）

入口：[angdata.f90](../../src/appl/ris4/angdata.f90)，调用端为 `ris_cal.f90` / `ris_cal_mpi.f90`。
空和两字节截断缓存触发运行时 EOF（退出 2）；缺文件及普通未完成尾记录则正常返回不可用。

先固定缓存缺失、不完整、不可读的行为契约，再检查 OPEN/BACKSPACE/READ/REWIND 和关闭路径。
现有行为允许不完整缓存重新计算；不能只把未检查 READ 改成另一个 STOP 就认为完成。
串行及 MPI root 调用路径分别验证，MPI 数据广播前有明确状态同步。

必要测试：缺文件、合法结束记录、非结束记录、空/截断/短记录、读取错误、失败后再次调用，
加 root 失败时整组 MPI 非零退出且无挂起。使用生产过程，正常角系数结果保持一致。

### S2：JJ2LSJ 唯一标签读取（P2，源码确认，局部复现）

入口：[jj2lsj_code.f90](../../src/appl/jj2lsj/jj2lsj_code.f90) 的 `uniquelsj`。
首行 READ 未检查；后续只处理 `ios==-1`。从原读语句提取的探针得到正 IOSTAT 5010，未进入 EOF 分支。
旧复核没有运行完整巨大工作区，不得称为完整唯一标签流程故障复现。

明确正常结束、转换错误、空级数/空分量的行为，使用命名 EOF 常量和非零失败，
避免读失败后消费字符串/系数或使用尚未设置的选择下标。
保持唯一标签分配算法和输出格式；正常输出与基线比较，补完整小夹具及损坏输入测试。
不得通过缩小生产容量或改变标签算法来使测试方便。

### S3：实常量 kind（P2，独立数值改动）

旧 C021 的 97 条中，77 个字面量本身精确，20 个会先按默认实数舍入。
四份 SCF 的 `0.001*accy` 在人工临界值上有分支差异，但没有实际原子计算失准的证据。
按四份 SCF → rwfnestimate → QED/矩阵判据 → 输出阈值分别核定和验证。

不要一次性机械给全部实常量加后缀；检查表达式的实际运算 kind、外部接口和比较目的。
`SLAMCH` 保持单精度返回 ABI；三份 `getrmp` 的 `cnum` 是未用声明，不属于数值精度缺陷。
默认实数运算的内存打印另列低优先级，不能与收敛判据的科学影响混为一谈。

必要测试：阈值两侧、典型正常值、原有数值回归；记录任何输出/迭代差异及原因，不能为了通过而事后放宽容差。

### S4：接口与防御性改进（P3）

旧加强探查中 1,107 个上下文的 51 个失败来自 48 份接口的维度变量声明顺序，
维度名都有整数声明；不是当前生产配置不能编译，也不是 51 个漏声明错误。
先将维度/长度声明移到依赖声明前，再按作用域加入 IMPLICIT NONE，核定实现与接口一致性。
不放宽生产 Fortran 标准，不批量猜测 INTENT，不改变回调 ABI。

指针默认 NULL、MPI worker 输出重定向诊断等按实际生命周期和失败行为独立验证。
没有可达错误证据的条目保持“规范/防御性建议”，不伪装成已修复缺陷数量。

## 4. 已确认的工具限制与不应自动修改的内容

- `rangular_input` 的状态在 BLOCK 外立即检查，是跨作用域分析误报；先核对迁移后的当前位置。
- NP 清理路径保留原错误状态，不能因 CLOSE 状态未使用就认定失败被接受；INQUIRE 输出引用可单独加强。
- fortls 的 `block_*` 数组赋值解析、两份 `vpint` 的 fixed/free-form 误判、外部 MPI 模块来源已有对照。
- Fortitude 续行/预处理 E001 和 SIXJ3 的 PORT051 有编译器对照；工具失去解析覆盖也应如实记录。
- C182 多对象分配已有终止/清理保护；C101 指针建议不等于十三处已复现野指针。
- rangular 重启分支不可达有保护性 STOP，删除 STOP 不等于实现重启。
- 缺省分支、名称遮蔽、USE ONLY、可变模块状态需要调用链核定，不能以诊断数替代缺陷数。

不运行全仓库自动 `--fix`，不整体屏蔽 C 类规则，不以修改输入过滤或降低编译检查获得表面全绿。
