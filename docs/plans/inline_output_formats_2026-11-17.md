# 输出格式在使用处显式书写

日期：2026-11-17。状态：待实施，仅记录需求。
基准：HEAD `3e02e0f` 加当前未提交的静态诊断与四批风格修改。

## 目标

后续将 suite 中通过数字标签引用 FORMAT 的输出，全部改为在使用处直接书写格式字符串，
让读者在 WRITE/PRINT 处看到各输出项采用的格式描述符。
这里的“明确变量类型”指明确整数、实数、字符等的输出格式，不改变变量声明、kind 或数值精度。

例如当前 `src/appl/rmcdhf/strsum.f90`：

```fortran
write (24, 300) nuclear_charge
300 format("The atomic number is ",1f14.10,";")
```

目标写法：

```fortran
write (24, '("The atomic number is ",1f14.10,";")') nuclear_charge
```

保留原格式描述符，不用列表导向的 `*` 替代。`write(unit, *)` 现有输出不在本次标签迁移范围内。
示例外层单引号用于容纳格式字符串内部的双引号；实际实现按等价转义及现行风格规则处理。

## 实施要求

1. 按共享库和应用分批，将所有数字标签格式输出内联，覆盖 WRITE、PRINT 及预处理分支。
   多个输出点复用一个 FORMAT 时，每处保留完整且等价的格式字符串，长格式使用合法续行。
2. 保持输出单元、输出项顺序、宽度、小数位数、指数格式、比例因子、重复组、格式回退、
   空格、字面文本、换行、ADVANCE、IOSTAT 和错误处理不变。
3. 删除 FORMAT 定义前，检查同一程序单元的全部引用。若 READ 等仍引用该标签，先记录并
   处理依赖，不能留下悬空引用；输入格式的迁移须保留原读取契约并做读回验证。
4. 不把其他用途的语句标签（例如跳转和循环终点）当作 FORMAT 删除，不改变计算表达式和类型。
5. 保护其他未提交修改；导入 RMCDHF 源码变更按现有机制追加来源快照，不覆盖历史快照。
