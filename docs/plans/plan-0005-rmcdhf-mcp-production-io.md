## 阶段 3 状态

已验证 Zn I AS2 三轮 EOL 的 A/C 数值一致性和可重复的全 SCF 墙钟下降。生产文件系统的实际读盘减量、
B 对照及目标资源预算仍待验收。[阶段 3 实施过程](2026-11-23-plan-0005-rmcdhf-mcp-phase3.md) · [实测记录](../reviews/evidence-0025-rmcdhf-mcp-phase3-benchmark.md)

| 验收项 | 已有结果与缺口 |
| --- | --- |
| 数值与墙钟 | 服务器 XFS 上的 48-rank 作业 14、15，以及本机 Btrfs 和 XFS 上的 8-rank A/C 对照均通过迭代能量、停止状态和输出哈希比较。每个平台的冷、热配对均测到 C 的全 SCF 墙钟缩短。三轮上限的对照覆盖固定迭代数下的回归。 |
| 实际读盘 | 服务器作业 15 的势系数阶段两版读盘计数均为零，冷态全 SCF 读量仍增加 94.32 MiB。服务器矩阵装配分段尚待采集。本机两种文件系统上的冷态势系数读量都随配对变化。 |
| 页驻留与读盘位置 | 逐轮诊断包已实现并在本机 XFS 验证。在一组冷态复跑中，C 从最后一个初始矩阵块装配结束时的 17.74% 降至首次势系数构造前的 4.76%。首轮首次构造读了 3,857.53 MiB，后续两轮读量均为零。页回收原因和目标服务器的相应阶段仍待核查。 |
| 资源与路径归因 | 已测本机生成峰值和两种 MPI 布局的单 rank 峰值 RSS。目标作业的内存预算、生成期磁盘峰值和分片复用成本仍待核对。B 已有历史小样本逻辑读取量，目标文件系统仍缺可追溯的 B 构建及配对数据。 |

## 对照方法

| 对照路径 | 比较目的 |
| --- | --- |
| A．旧 MCP 与旧扫描 | 测量各阶段和各 rank 的基准读量与等待。 |
| B．旧 MCP 与一次流式收缩 | 隔离减少扫描和复用收缩的收益。 |
| C．带目录 MCP 与一次流式收缩 | 核对直接跳块、按需读取、生成成本和驻留内存。 |

A 使用 `c1377aa0`，C 使用 `0f356733` 的基准快照。B 待找回旧格式流式收缩构建后复测。A 和 B 使用相同布局的旧格式 MCP，
C 用配套的 `rangular_mpi` 重生成。固定基组、交互分区、目标根、冻结列表、初始轨道、SCF 参数、MPI 布局和
文件系统。冷、热态分别配对并检查启动前缓存。数值回归核对组收缩、矩阵、乘子、径向势、迭代能量、停止状态
及输出轨道。选用实际需要重复构造轨道势的多块算例。

记录应用层逻辑读取字节、各 rank 的实际 I/O、等待和每轮 SCF 墙钟，同时记录峰值 RSS、生成期磁盘峰值和最终文件大小。
`--mcp-trace` 记录逻辑读取量。进程 `read_bytes`、设备读量和页驻留应按各自窗口核对。性能对照关闭 `--mcp-verify`，
用独立的矩阵分段与页驻留诊断作业保存各自的采样口径。[外部采样计划](plan-0003-rmcdhf-mpi-stall-diagnostics.md)

## 待实施与验收

1. **服务器矩阵分段。** 在作业 15 的目标 XFS 和 48-rank 布局上复跑矩阵分段包。用首次矩阵、后续矩阵、
   势系数和其余 SCF 窗口定位冷态额外读量。逐组检查冷、热态的页驻留、读量和数值输出。
2. **服务器页驻留与设备采样。** 分开运行逐轮诊断包和性能基准。诊断时同时采集设备读量、页回收和内存压力，
   用 `timestamp_ns` 与外部采样的 UTC 时间对齐。先覆盖从最后一个初始矩阵块结束到第一次势系数构造返回的区间，
   再核对后续轮次中各 rank 的首次读盘事件。[采样器运行说明](../implemented/design-0021-rmcdhf-mpi-diagnostics.md)
3. **补齐生产判据。** 如果目标 XFS 上的 Zn I AS2 仍在 A 的势系数窗口测得零读盘，选取 A 在该窗口确实发生读盘
   的代表性生产算例。按重复配对核对 C 的势系数读盘量、最慢 rank 势系数墙钟和全 SCF 墙钟是否均下降。
   按目标作业的单 rank 内存预算、生成期磁盘峰值和分片复用次数核算资源成本。
4. **补齐 B 并确定覆盖范围。** 取得带源码和构建证据的 B 后，在同条件下比较 A→B 的收缩复用收益和 B→C 的目录格式增量。
   其他 MPI 求解器的性能验收使用各自的历史基准。串行 `rangular` 和 RMCDHF 的目录格式接入另行评估。
